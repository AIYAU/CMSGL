# Release Manifest

This repository contains only the proposed CoSGL / S2G-CCSGCL method code.

## Included

- `cc_sgcl/`: proposed method implementation
- `scripts/`: method training, evaluation, threshold calibration, and summaries
- `configs/`: main reproducibility configurations
- `third_party/hyliosr_compat/`: small compatibility helpers used by the data protocol
- `data/README.md`: dataset placeholder
- packaging files: `pyproject.toml`, `requirements.txt`, `LICENSE`

## Excluded

- comparison-method adapters
- external baseline repositories
- datasets and prepared arrays
- trained weights and checkpoints
- generated outputs, figures, logs, and manuscript files
